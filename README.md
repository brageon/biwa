# Beneficial Impact

BIWA is a verbal compiler for ethical and predictive decision modeling using **ontological nodes**. Built for institutional designers. Monte-Carlo simulation decides the ranking hierarchy.

<h2>Setup</h2>

```
git clone https://github.com/brageon/biwa.git
python3 -m pip install spacy, pickle
python3 oanc/king.py | sort -k2 -nr
```
